External Authentication System

Keyboardless Security Infrastructure

This system provides secure, hardware-isolated terminal and partition authorization via mobile PWA, eliminating manual passphrase entry.
🔑 Supported Core Integrations:
  • • LUKS & Crypttab — Pre-boot full disk decryption
  • • Terminal / Sudo — Privilege escalation in OS
  • • User Auth — Lock screen and session management
📡 Air-Gapped & Wired Channels:
Primary authentication runs via dynamic QR codes. Backup channels support secure USB PTP-mode file exchange and acoustic Audio-modem trills.

Data Exchange via QR Codes
This is the primary mode designed for secure passphrase transfer between isolated devices using dynamic QR codes.
Follow steps below (expand item for details):
* Run the extAuth console script (or press enter in booting LUKS one) on the destination computer.
* The PC monitor will display a QR code containing the session public key and metadata.
1. In this app, tap the  white "Scan" button and scan the QR code from the PC screen.
2. Once the destination is recognized, enter your current authorization key/passphrase.
* Tip: You can use the Dice button 🎲 to generate a secure new passkey if needed.
* Compare the  yellow OTP code on the computer screen with the code in this app.
1. Tap the yellow QR button .
2. The app will generate an animated sequence of sequential QR code chunks.
3. Hold your smartphone screen up to the computer's active camera to read the sequence.
* All data exchanged via QR codes is fully encrypted using a cryptographically strong algorithm.
* Complete protocol details and full open-source code can be checked on the project GitHub page.

USB Data Exchange in PTP Mode
This mode can be used in case of absence or problems with the device cameras.
Follow steps bellow (expand item for details):
1. Connect your smartphone to the computer using a USB cable.
2. Open the Android notification shade, tap "USB Charging", and select: "Image Transfer (PTP)".
* Only AFTER enabling PTP mode on your phone, start (or resume) the extAuth script on the PC.
* The script will detect your phone and create a special file in your "Pictures" folder.
1. In this app, tap the white "Scan" button.
2. If a file selection window appears, go to the "Pictures" folder.
3. Select the file named: extAuth.txt.
(The app will read the metadata and the PC's public key).
* Compare the  yellow OTP code on the computer screen with the code in this app.
* They MUST match exactly!
* If the numbers are different, connection is unsafe. Close everything and start over.
1. If the OTP codes match, tap the YELLOW button with the QR code icon.
2. The app will encrypt your passkey and save it back to the same file.
3. The computer will detect data update, decrypt it, and log you in.
Data Exchange via Audio Channel
For now, it’s just a teaser; the functionality is still under development :(

This backup mode can be used in case of absence or optical problems with the device cameras.
Follow steps below (expand item for details):
1. Turn on the AUDIO switch in the PWA toggles line.
2. Tap the main white button to turn on the microphone and start listening to the air.
* Put the smartphone microphone close to the PC speaker.
* The PC will broadcast an amplitude-modulated sound trill (2ms per bit).
* The app will automatically catch the preamble and calibrate the phase.
1. Check that the yellow OTP codes match exactly on both screens.
2. The app will immediately broadcast the encrypted audio response back into the air.
3. The PC monitor will detect the answer and close the authorization process automatically.
